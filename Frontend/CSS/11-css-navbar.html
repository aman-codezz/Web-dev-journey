Here we are going to create an table for products

Product Name Price Quantity
Product 1 $10 100
Product 2 $20 50
Product 3 $15 75

This is a simple product table created using HTML. It contains three columns: Product Name, Price, and Quantity. Each row represents a different product with its corresponding details. You can customize the table by adding more products or changing the styling as needed.

To create a table in HTML, we use the <table> element, and within it, we define the header row using <tr> for the row and <th> for the header cells. The data rows are created using <tr> for each row and <td> for the data cells. You can also apply CSS styles to enhance the appearance of the table.

Overall, tables are a great way to organize and display data in a structured format on a webpage. They can be used for various purposes, such as displaying product information, schedules, or any other tabular data.

Feel free to modify the table and add more products or customize the styling to suit your needs!

Remember to always ensure that your tables are accessible and properly structured for better user experience and SEO.
